# Design context

- Audience: Chinese learners following the AI Agent curriculum.
- Job: navigate eighteen ordered stages, see what has been verified, and open the matching local practice project.
- Visual direction: a technical field notebook rather than a generic course dashboard.
- Palette: ink `#18243a`, paper `#f4f7fb`, blue `#2767d8`, cyan `#23bdd0`, muted `#6d7d95`, border `#dce5f0`.
- Type: system Chinese sans for readable prose; monospace for stage numbers and status labels.
- Signature: a continuous numbered learning rail connecting stage cards.
- Behavior: links are real anchors; stage pages include previous/next navigation and a clear provenance badge. Responsive layout and visible focus states are required.
