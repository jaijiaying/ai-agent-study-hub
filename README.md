# AI Agent 学习地图

以百战程序员「AI Agent 智能体开发大厂孵化器」截图中的预科与 01–17 阶段为范围，制作的本地知识网页。

## 查看

直接打开 [index.html](index.html)，或在本目录运行：

```bash
python3 -m http.server 8081
```

再访问 http://127.0.0.1:8081 。每个阶段有独立的 `stage-XX.html` 页面。
